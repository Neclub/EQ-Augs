Slot2 Type 7/8 Aug Report

Charm and Range often cannot use the top type 7/8 augs (many say “All except Charm, Range…”). Recommendations for those slots use only augs that fit. Artisan's Prize is Ear-only and is recommended for Ear only when marked as owned. For WAR, MNK, RNG, BST, and BRD, Feet recommends the highest-AC type 7/8 aug that fits (class must be present in the inventory filename, e.g. Char_server-WAR-Inventory.txt). Lore augs can only be equipped once: recommendations assign the best remaining Lore aug starting at Ear-1, then Ear-2, then down the slot list.
